# 穆祉丞的手机

玩家以穆祉丞的视角探索手机。主要人物为王橹杰、穆之友（角色名）。锁屏密码为 2711。

主剧情开放微信、短信、微博、抖音。主剧情结束后点击“继续探索手机”，额外开放相册、浏览器；这些应用不参与主剧情。其他应用禁止打开，包括备忘录、电话、文件、哔哩哔哩、网易云、App Store 和锁屏相机。桌面布局导入与搜索不会放宽权限。

## 剧情顺序

1. 解锁 2711，收到王橹杰的新微博通知。主页文字和五条微博按作者截图顺序排列。
2. 首次打开微博，5000 ms 后收到短信通知；首次短信为作者给出的蜜雪冰城柠檬水分期逾期文案，号码保持未知。
3. 进入短信，立即收到“微信：有信息需发送”。进入穆之友会话，玩家点击输入框发送短信截图；自动回复“？谁发的这么抽象”；玩家再点发送“不知道”；自动回复“我好像知道了”和抖音截图。
4. 弹出抖音通知。打开作者指定的“短信爱”图文，立即收到微信提示。
5. 返回穆之友会话，玩家依次点击发送作者指定的五条回复，穆之友按截图顺序自动回复。最后玩家发送“我其实好像知道是谁”，微信剧情结束并弹出最终短信通知。
6. 进入未知号码会话，按作者五张截图逐条点击发送；对方按顺序自动回复。最后发送“嗯”后等待 1000 ms，主剧情结束，开放自由探索。通关后微信额外显示王橹杰的会话。进入即可直接查看作者三张截图中的 19 条历史消息，保留五组时间与发送失败标记；历史会话采用浅色界面，全部消息已存在，无需点击发送，也不会自动补发或影响主剧情。

各节点只触发一次；延迟、对话和通知随存档保存。发送按钮根据隐藏消息的 sendOnTap、sendPhase、sendAfter 决定下一条可发送内容，等待对方回复期间禁用。读到一条消息不会代替玩家发送回复。
